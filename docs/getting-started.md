# Bien démarrer

## Prérequis

- une instance n8n accessible ;
- un compte GitHub uniquement si vous souhaitez cloner le dépôt avec Git ;
- les comptes et autorisations nécessaires aux services utilisés par le workflow choisi.

## Parcours recommandé

1. Lire le `README.md` du projet ou du template choisi.
2. Examiner ses prérequis, entrées, sorties et contraintes.
3. Importer son fichier `workflow.json` dans une instance de test.
4. Créer ses propres credentials dans n8n.
5. Remplacer les identifiants, URL et valeurs d'exemple.
6. Tester les cas nominaux et les erreurs attendues.
7. Activer le workflow uniquement après validation.

## Choisir entre projet et template

Un **projet** documente une automatisation complète répondant à un besoin précis du cours. Un **template** fournit une base générique destinée à être adaptée à un autre contexte.
